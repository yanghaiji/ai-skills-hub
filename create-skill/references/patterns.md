# 常见模式

## Wrapper Skill

包装外部工具或 API。

```markdown
## Setup
Install CLI: `npm install -g tool-name`

## Usage
Run: `tool-name command --option`
```

## Workflow Skill

引导多步流程。

```markdown
## Steps
1. Gather input via AskUserQuestion
2. Process with script
3. Present results
```

## Reference Skill

提供知识/上下文。

```markdown
## References
Load `references/topic.md` when needed for detailed info.
```
